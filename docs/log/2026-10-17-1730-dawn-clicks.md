# The dawn haze swallowed every click on the map, 2026-10-17

`#dawn` (the opening haze, #445) is a full-screen layer in `#hud`. `.dawn { pointer-events: none }` lost to `#hud > * { pointer-events: auto }` (an id beats a class), so after it faded it still caught every left and right click meant for the map: no selecting, ordering or placing with the mouse. Keyboard and HUD buttons still worked, so the smoke test passed.

Fix: `#hud > #dawn` joins the list of HUD layers that let clicks through (`src/ui/style.css`). Found in Chromium while trying patrol (#454): `document.elementFromPoint` over the map returned `DIV#dawn`; after the fix it returns the canvas and a click issues its command.
