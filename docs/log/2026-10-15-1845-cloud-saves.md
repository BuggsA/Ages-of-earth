# Cloud saves (2026-10-15 18:45 UTC)

The owner asked: "Are you able to add cloud saves please?"

**Built.** A save can now live on the server as well as in the browser.

- `worker/vault.ts`: a `Vault` Durable Object, one per vault key. It keeps the latest save text in 512 KB pieces (a stored value may hold 2 MB; a four-player large map saves at about 0.9 MB), written in one transaction, and refuses anything over 6 M characters (413) or that isn't a save (400). An alarm empties a vault nobody has opened or written for 180 days, so abandoned saves don't pile up.
- `worker/index.ts`: `POST /api/vaults` hands out a key; `GET`, `PUT`, `DELETE /api/vaults/KEY` reach that key's vault. Anything else under `/api/vaults` is 404.
- `wrangler.toml`: a `VAULTS` binding and migration `v2` adding the `Vault` class (new class only; nothing deleted or renamed; routes untouched).
- `src/net/vault.ts` (keys: 16 of the room codes' 32 unmistakable letters, about 80 bits) and `src/net/cloud.ts` (the browser's key in `localStorage` as `ages-vault`, put and get).
- `src/main.ts`: **Save to the cloud** in the menu; **Cloud save…** on the title screen shows your key, continues from it, or takes a key from another device. A browser with a key pushes its save every five minutes of play and on quitting to the title.

**Security.** No accounts: the key is the secret. It's 80 random bits from `crypto.getRandomValues`, only ever in a URL path over HTTPS. It touches nothing in online rooms. Anyone can create vaults; each holds at most 6 MB and expires, so the worst case is bounded storage on the owner's Cloudflare account (Durable Object SQLite storage).

**Seen.** `wrangler dev` + headless Chromium: browser A saved a seed-7 match at tick 86; a fresh browser context with no storage, given the key typed in lower case with dashes, resumed seed 7 and played on to tick 130; no page errors. curl round trip of a 1.5 MB save byte for byte. Not seen: the live deploy on Cloudflare, a phone.

**Next.** Several slots per key; a QR code or link (`?vault=KEY`) to carry the key to a phone; keeping the campaign's stars and the Web of Ages discoveries in the vault too.
