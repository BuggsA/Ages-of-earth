# Seed Atlas — 2026-10-14 11:33 UTC

Issue #80, lane:tooling, branch `gpt6/80-seed-atlas`.

## Why

Ages can diverge only on certain seeded worlds (bog iron), while ruin finds and neutral trading posts create other distinct openings. Testing these possibilities by launching each match is slow; discovering them from world generation itself is deterministic, quick, and reproducible.

## Build

- Reads only `generateMap` (the same function a real match uses); never changes or steps simulation state.
- CLI scans an inclusive seed range with validated size, map type, 2–4 players, optional iron/ruin/post filters.
- Table shows relevant counts and buried finds, including straight-line distance to the nearest town (clearly not a path length); JSON preserves the complete recipe.
- Unit tests check flag parsing, filtering, reproducibility against actual mapgen output, and range reporting.

## Compatibility

No numbers in `src/sim/data.ts`; no changes to AI, visuals, Worker, replay or save shape. A tool for testers; reveals ruin spoilers, never shown in game.
