# Hands find their own work (#344), 2026-10-17

Owner's note #344: managing people is still hard; find where the friction lives.

- Measured with a new headless script, `scripts/idle-audit.ts [seed] [minutes] [size] [--no-rally] [--no-hunt]`. A plain scripted player; it counts each time a citizen falls idle and why.
- Found and fixed, for the player's people only (the computer re-tasks its own; `sim.ts 3 medium 30` checksum unchanged, 2086345273):
  - A rally flag on a resource now keeps the resource kind (`Building.rally.kind`, optional, so no save bump). When its tile runs out, new hands take the nearest of that kind near the flag, two to a node (`rallyNode`, `units.ts`; spawn in `game.ts`). Before this, every citizen after the first felled tree walked to bare ground and stood idle.
  - A hunter done with a carcass spears the next deer within `AUTO_WORK.herd` (8) tiles (`gather` order carries `meat`).
  - A food gatherer with no bush or carcass near takes an unworked field within `AUTO_WORK.farm` (12) tiles. Fields already headed for by someone else are skipped (`headedFarms`); the same skip now applies to #408's builder rule, which could send two builders to one field.
  - Took over #352 (stale): a citizen trained with no rally gathers within `AUTO_WORK.trained` (14) tiles.
