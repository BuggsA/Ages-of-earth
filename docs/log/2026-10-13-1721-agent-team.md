# 2026-10-13: the multi-agent system, ported from Homeward Bound

**Asked:** "I am thinking about getting this concept ported in ages of empire could you help?" (the owner's choices: `docs/rulings.md`, 2026-10-13).

**Built:**
- `AGENTS.md`, the one copy of the rules for every agent tool; `CLAUDE.md` imports it and adds the Claude-only parts.
- `docs/team.md` (the board, lanes for this codebase, claims, handoffs, branches, merging, saves), `docs/successors.md` (chains and tiers), `docs/status.md`, `docs/rulings.md`, this log, `.github/ISSUE_TEMPLATE/task.md`.
- Test tiers: `npm run check` (quick), `npm run test:slow` (`tests/slow/`, empty for now), `npm run check:full`; `vite.config.ts` picks the tier from the Vitest mode.
- GitHub Actions: `ci` (build + unit tests on pull requests and `main`) and `periodic` (the full tier daily on `main`, which opens a `ci-periodic` issue when it fails).
- `.claude/hooks/session-start.sh` and `.claude/settings.json` (dependencies at session start, effort per tier).
- On GitHub: `main` made from a29e3ad, #1 retargeted to it, #2 "Start here" opened.

**Changed from Homeward Bound, and why:**
- **Checks.** Homeward's rule (the full browser suite, about 22 minutes, on every merge, re-run whenever `main` moved) cost every agent half an hour per merge. Here agents run a check of about 20 s, GitHub runs the merge check, and the slow tier runs once a day.
- **CI logs agents can read.** Homeward's #118 stalled on a Cloudflare check whose log no agent could open; GitHub Actions logs are readable through the GitHub tools.
- **One copy of the rules.** Homeward's "Start here" issue drifted from `docs/team.md`; here #2 only links.
- **Lanes by file, not by feature.** Features here cut through `src/sim/`, `src/render/`, the HUD and `main.ts` together (every gameplay commit so far did), so `rules` is effectively one step at a time beside one `ai`, `look` or `online` step.
- **Dropped:** Muse and the art lane (models are made in code), phases, the economy report, Homeward's tone rules.
- **Hard stops** adapted: Durable Object data, routes and domains, and room security added; the save rule became "bump `v`", since saves aren't tied to a build.

**Verification:** `npm run check` → 56 passed, exit 0, 15.5 s; `npm run test:slow` → "No test files found, exiting with code 0"; a temporary `tests/slow/probe.test.ts` ran under `test:slow` (1 passed) and not under `npm test` (56), then was removed; `npm run check:full` → built, 56 passed, exit 0; the dev server answered 200; both workflow files parse as YAML, the failure-report script passes `bash -n`, and `actions/checkout` and `actions/setup-node` have `v5` tags. The workflows themselves haven't run yet: `ci` first runs on this branch's pull request, `periodic` once `main` is the default branch.

## Then: creative freedom

The owner asked for agents to have "a lot of creative freedom" and that "they shouldn't need approval for a lot" (`docs/rulings.md`). So `AGENTS.md` §2 is now "You're a co-designer": agents pitch (`.github/ISSUE_TEMPLATE/pitch.md`) and build their own ideas without approval, sign them in `docs/design-notes.md`'s new "Designers' notes", and pause only at hard stops. An empty board no longer ends a successor chain (`docs/successors.md`), so chains run to their caps. Homeward Bound's opposite rules ("Do not be creative", "human owns taste") were deliberately left out.
